# 🎙️ Reference Voice Recordings Directory

Categorized repository of reference voice recordings organized across 17 distinct subfolders:
- `Accessibility`
- `Advertisement`
- `Announcement`
- `Audiobook`
- `Conversation`
- `Customer Support`
- `Documentary`
- `Education`
- `Gaming`
- `Meditation`
- `Narration`
- `News`
- `Podcast`
- `Poetry`
- `Presentation`
- `Social Media`
- `Storytelling`

---

## 🚀 Usage

Any `.wav` or `.m4a` file placed in `voices/` or its subfolders is automatically indexed by `dashboard.py` and `launcher.py` as an selectable reference voice profile for zero-shot voice cloning.
